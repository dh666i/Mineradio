# Mineradio v3.0.1

本版本完善网易云多类型搜索与歌手详情播放，接入五平台能力，并加入可校验、可回退的 blockmap 差量更新。

## 搜索与歌手详情

- 网易云搜索新增“综合 / 单曲 / 歌手 / 专辑 / 歌单”分类。
- 综合结果同步展示歌手、专辑和歌单；各分类支持独立分页与继续加载。
- 歌手详情支持分页获取网易云与 QQ 音乐热门歌曲。
- 歌手页新增“播放前100首”，避免一次载入歌手的全部曲库；歌曲不足 100 首时播放当前可用内容。
- 搜索与详情请求会明确处理登录失效、空结果、分页结束和上游请求失败。

## 五平台与分享歌单

- 网易云音乐、QQ 音乐、酷狗音乐、汽水音乐与 Spotify 均提供账号状态、搜索、歌单、歌词和播放分发入口；受版权、会员或平台限制的歌曲会明确提示，并优先尝试其它已支持平台的匹配版本。
- 搜索结果支持全拼和首字母匹配；各音源独立分页，临时失败时可单独重试，不会丢失其它来源的结果。
- 搜索框可直接粘贴五平台歌单分享链接。网易云、QQ 和 Spotify 使用现有歌单接口；酷狗支持公开接口、`gcid` 解码与 H5 回退；汽水从公开分享页读取可见曲目，平台未公开完整内容时会标记为部分导入。
- 导入歌单只保存在本机播放器内，可从侧栏移除，不会修改原平台歌单。

## 界面与交互

- 音量面板只在点击音量按钮后展开，再次点击或点击外部关闭，不再因悬停意外弹出。
- 当前队列的关闭按钮改为固定尺寸图标，避免按钮在标题栏中异常拉伸。

## 播放稳定性与安全

- 连续播放、自动换源和异常恢复均增加时限、次数和当前歌曲归属校验，迟到的网络响应或媒体事件不会覆盖用户已经切换的新歌曲。
- QQ 音乐取链对 vkey 请求、可播探测和整个请求分别设置上限；高音质候选不可播时会在有限次数内回退兼容音质。
- 封面和音频代理逐跳校验 DNS 与目标 IP、限制重定向和 MIME，并支持 Range、HEAD、超时和下游断开取消。汽水加密音频保留受限缓存与解密流程。
- 酷狗账号相关搜索与取链只允许 HTTPS，底层请求会在发送 Cookie 或 Token 前拒绝任何明文 HTTP 回退。
- Windows 打包工具升级到 electron-builder `26.15.7`；打包内容继续排除 electron-builder 等开发依赖。
- 关闭的 Web Audio 上下文会重建并重新绑定当前媒体；“关于”页的缓存清理只删除网络和节奏分析缓存，不会删除登录状态、设置或歌单。

## 差量更新

- 更新器支持 Electron blockmap 差量下载；存在可复用的旧安装包和块清单时，只请求新版本中发生变化的数据块。
- 本地复用块逐块校验，拼装完成后继续执行完整安装包大小与 SHA512 校验；存在 Authenticode 签名时继续校验签名。
- 差量条件不满足、块校验失败、线路不支持 HTTP Range 或节省量不足时，自动回退完整安装包下载。
- 完整下载成功后保存对应 blockmap，供后续版本差量升级复用。

## 安装提示

- 默认 Windows 构建为无签名安装包，Windows 可能显示未知发布者；项目仍保留显式自签构建命令，供需要测试签名链路的开发环境使用。
- 应用内更新会继续校验 GitHub 更新元数据中的文件名、大小与 SHA512；建议只从 `dh666i/Mineradio` Releases 下载，并核对 Release 提供的 SHA256。
- 已安装 `v1.5.4` 的用户需要手动下载并覆盖安装本版本：`v1.5.4` 的旧更新器要求新包沿用原证书，无法打开无签名的 `v3.0.1` 安装包。
- 从 `v1.5.4` 到本版本的第一次升级仍为整包下载；安装 `v3.0.1` 后，后续版本才能使用新的差量更新链路。
- 从旧版本覆盖安装时，播放设置、登录状态、队列和本地用户资源应保留。
- 本 Release 同时提供 macOS `x64`（Intel）和 `arm64`（Apple Silicon）DMG/ZIP 预览包。预览包仅使用 ad-hoc 本地完整性签名，没有 Apple Developer 身份签名或 Apple 公证，首次启动可能需要在 Finder 中右键“打开”或通过“系统设置 > 隐私与安全性”放行。

## 平台限制

- Spotify 当前作为元数据来源，不能直接提供 Spotify 音频；播放时会匹配其它平台的可播版本。首次连接需要用户自己的 Spotify Client ID，授权使用官方 PKCE OAuth，不收集 Client Secret。
- 汽水音乐完整播放依赖官方 PC 客户端的登录会话；公开分享页未提供全部曲目时只能部分导入。
- 酷狗、QQ 音乐与汽水音乐仍受账号登录完整性、会员权益、版权、地区和上游接口变化影响。
- 本地最多保留 30 个分享歌单，每个最多 500 首；汽水公开分享解析最多读取 300 首。
- macOS 已通过 GitHub Actions 双架构构建和自动化平台隔离检查，但尚未完成真机启动、登录、播放、媒体键、全屏、多显示器及 Gatekeeper 全流程验证；应用内安装器更新暂只支持 Windows。
