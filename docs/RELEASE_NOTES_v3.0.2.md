# Mineradio v3.0.2

本版本集中优化搜索界面、账号来源排序和无效音源处理，并修复过滤结果后的多平台分页问题。

## 搜索界面

- 移除搜索框下方常驻的“综合 / 单曲 / 歌手 / 专辑 / 歌单”类型栏，让默认搜索区域更简洁。
- DIY 模式原有的平台来源栏继续保留，可按网易云、QQ 音乐、酷狗音乐、汽水音乐或 Spotify 单独搜索。
- 综合结果仍会展示单曲、歌手、专辑和歌单，并保留“查看全部”入口；分类结果可以直接返回综合搜索。
- 修复在分类详情中再次点击当前来源标签后画面与内部状态不一致的问题。

## 账号来源优先级

- 综合搜索以当前选中的有效登录账号来源为第一优先级。
- 其他已登录且未过期的来源排在第二优先级，未登录公共来源随后展示。
- 如果首选账号已经过期，会自动使用另一个仍有效的登录账号作为主要来源。
- 单曲、歌手、专辑、歌单以及“播放全部”的去重选择使用一致的来源优先级。
- 显式选择某个平台时仍只搜索该平台，不会混入其他来源。

## 无效音源与分页

- 不再展示缺少真实平台歌曲 ID、明确下架、版权不可用或服务端明确标记不可用的结果。
- 歌曲在播放时确认无法取链或媒体地址损坏后，会在当前账号与会员状态下短期隐藏，避免重复点到同一个死链。
- 需要登录、会员权限、跨平台换源或用户手动点击播放的歌曲不会被误删。
- QQ 音乐、酷狗音乐和汽水音乐改用过滤前的原始结果数量推进分页，避免加载更多出现重复、跳页或提前结束。

## 安全与安装

- 地址解析依赖升级到修复版本，生产依赖安全审计为零告警。
- Windows 继续提供无签名 x64 安装包，并通过 `latest.yml` 的大小和 SHA512 以及独立 SHA256 清单校验完整性。
- 本版本支持从 `v3.0.1` 使用 blockmap 差量更新；条件不满足时会自动回退完整安装包。
- macOS 同时提供 Intel x64 与 Apple Silicon arm64 的 DMG/ZIP 预览包，使用 ad-hoc 本地完整性签名，未进行 Apple Developer ID 签名或公证。
